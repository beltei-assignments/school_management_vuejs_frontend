# School Management System & Real Estate Property Management System

## Prerequisites 🧨🧨

Before you begin, ensure you have met the following requirements:

- NODE >= 20.0.0
- Node.js & npm

## Installation 🧨🧨

### Steps

**Rest APIs connection**

Location copy file from `.env.example` to `.env`
- `VUE_APP_API_SCHOOL_URL`: `"http://localhost:8000/api/"`
- `VUE_APP_API_PROPERTY_URL`: `"http://localhost:8080/api/"`.
- `VUE_APP_PROPERTY_BASE_URL`: `"http://localhost:8080"`.

**Following commands**
- Install dependencies: `npm install`
- Start: `npm run dev`

## Great! School Management System & Real Estate Property Management System!
- School Management System: http://localhost:3000/login/school
- Real Estate Property Management System: http://localhost:3000/login/property

**Following users**
- School Management System: `admin@example.com` | Password: `123`
- Real Estate Property Management System: `admin@example.com` | Password: `123`
